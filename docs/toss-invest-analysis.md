# 토스증권 UI/UX 및 기능 분석 리포트

> 분석일: 2026-03-25 | 목적: DI금융 서비스 개선을 위한 벤치마킹

---

## 1. 전체 사이트 구조

토스증권은 **4개 핵심 탭**으로 구성됩니다:

| 탭 | URL | 핵심 기능 |
|---|---|---|
| 홈 | `/` | 실시간 랭킹, 마켓 인덱스, 카테고리별 종목 탐색 |
| 피드 | `/feed/recommended` | 소셜 투자 커뮤니티, 유저 포스트/포트폴리오 공유 |
| 주식 골라보기 | `/screener` | 조건별 종목 스크리닝 (기본/재무/시세/기술 필터) |
| 내 계좌 | (로그인 필요) | 포트폴리오 관리, 주문 내역 |

**글로벌 요소**: 상단 검색바(`/` 단축키), 로그인 버튼, 우측 관심 사이드바(고정)

## 2. 홈 화면 분석

### 2.1 마켓 인덱스 바 (상단)
- 증시캘린더, 달러 환율, 나스닥, 나스닥100 선물, S&P500
- 가로 스크롤, 실시간 가격/등락률 표시
- "실시간 시세 확인하기 >" 링크로 상세 이동

### 2.2 3단 탭 구조
- **실시간 차트** | **지금 뜨는 카테고리** | **국내 투자자 동향**
- 기본 선택: 실시간 차트

### 2.3 필터 시스템
- 마켓 필터: 전체 / 국내 / 해외
- 정렬 기준: 토스증권 거래대금 / 거래량 / 거래대금 / 거래량 / 급상승 / 급하락
- "실시간" 드롭다운 + "투자위험 주식 숨기기" 토글

### 2.4 종목 랭킹 테이블
- 순위, 종목 아이콘, 종목명, 현재가, 등락률, 거래대금, 토스증권 거래 비율(매수/매도 바)
- **클릭 시**: 오른쪽 패널에 차트 + 커뮤니티 미리보기 (SPA 전환 없이 인라인)
- 매우 빠른 반응 속도

### 2.5 우측 사이드바 (고정)
- **토스증권 AI**: AI 요약 뉴스 카드
- **관심 주식 TOP 10**: 관심 그룹에 담은 종목 (비로그인 시에도 표시)
- **리모콘**: 내 투자 / 관심 / 최근 본 / 실시간 (아이콘 탭)
- 하단: 다크모드 토글(달 아이콘)

### 2.6 하단 티커 바
- 투자 유의사항 + 주요 지수(나스닥, S&P500, 코스피, 달러 인덱스 등) 실시간 스크롤

## 3. 피드 페이지 분석

### 3.1 레이아웃
- **좌측**: 추천 / 뉴스 탭 전환
- **중앙**: 소셜 피드 (무한 스크롤)
- **우측**: 주간 프로필 랭킹 + 주제별 커뮤니티

### 3.2 소셜 피드 기능
- 유저 투자 포스트 (텍스트 + 차트 캡처)
- 포트폴리오 공유 카드 (수익률 시각화)
- 좋아요, 댓글, 리포스트, 공유 버튼
- 유저 배지: "1억대 자산가", "주주" 등

### 3.3 커뮤니티 구조
- 종목별 커뮤니티 (해당 종목 상세에서 접근)
- 주제별 커뮤니티 (미국주식이야기, 국내주식토론 등)
- 주간 수익금/팔로워 급상승 랭킹

## 4. 종목 상세 페이지 분석

### 4.1 해외 종목 (KORU 예시)
- **헤더**: 종목 아이콘, 이름, 티커, 현재가($), 원화 환산가, 등락률
- **상단 메타**: 1일 최고/최저, 52주 최고/최저
- **액션 버튼**: 알림, 관심, 달러/$, 공유
- **탭**: 차트·호가 | 종목정보 | 뉴스·공시 | 커뮤니티

#### 차트·호가 탭 (기본 뷰)
3열 레이아웃:
- **좌측**: 차트 (1분/일/주/월/년 + 이동평균선 + 드로잉 도구 + 설정)
- **중앙 상단**: 호가 (로그인 필요)
- **중앙 하단**: 커뮤니티 미니뷰 (인기순/최신순) + 시세(실시간/일별)
- **우측**: 주문하기 패널
  - 주문 유형: 일반 주문 (드롭다운)
  - 주문방법: 수량 / 소수점 토글
  - 구매가격: 지정가 / 시장가 토글
  - 수량 입력 + 10%/25%/50%/최대 버튼
  - 구매가능 금액, 총 주문 금액
  - CTA: "로그인하고 구매하기" (빨간 버튼)

#### 종목정보 탭
- ETF 설명, 시가총액, 운용자산, 운용사, NAV, 상장일, 발행주식수
- **보유 비중 Top 10** (도넛 차트)

#### 뉴스·공시 탭
- 뉴스 / 공시 서브탭
- 최신순 / 관련도순 정렬
- 뉴스 카드 (제목, 미리보기, 출처, 시간)

#### 커뮤니티 탭
- 좌측: 커뮤니티 프로필 만들기 CTA + 주간 수익금 TOP 3 + 인기글 목록
- 중앙: 게시글 작성 입력 + 인기순/최신순 + 사용자 게시글 피드

### 4.2 국내 종목 (삼성전자 예시)
해외 종목과 동일 구조 + 추가 요소:
- **거래현황 탭** (추가): 투자자 동향 (개인/외국인/기관 매수/매도 바)
- 하단 패널에 **투자자 동향** 위젯 별도 표시
- 가격: 원화 표시, "어제보다" 변동 표현
- **화면 편집** 기능 (레이아웃 커스터마이징)

## 5. 주식 골라보기(스크리너) 분석

### 5.1 구조
- **좌측 사이드바**: 주식 골라보기 목록
  - "내가 만든" 섹션 + "직접 만들기" 버튼
  - "토스증권이 만든" 프리셋:
    - 연속 상승세 (인기), 저평가 성장주 (인기), 아직 저렴한 가치주
    - 꾸준한 배당주 (인기), 돈 잘버는 회사 찾기, 저평가 탈출
    - 미래의 배당왕 찾기, 성장 기대주, 쌍끌이 매수
    - 고수익 저평가, 안정 성장주
- **메인 영역**: 필터 + 결과 테이블

### 5.2 필터 시스템 (4대 카테고리)

#### 기본 필터
- 국가, 시장, 카테고리, 시가총액, 제외 종목 관리

#### 재무 필터
- **기업가치**: PER, PBR, PSR, PFCR, EV/EBITDA
- **성장성**: 매출액 증감률, 연평균 매출액 증감률, 매출액 연속증가, 매출총이익 증감률, 매출총이익 연속증가, 영업이익 증감률, 영업이익 연속증가, 순이익 증감률, 연평균 순이익 증감률, 순이익 연속증가, 영업이익 어닝 서프라이즈(국내), 순이익 어닝 서프라이즈(해외)
- **수익성**: 매출총이익률, 영업이익률, 순이익률, ROE, ROA
- **배당**: 배당수익률, 배당성향, 배당 연속지급, 순이익 연속증가(연도별)

#### 시세 필터
- **가격조건**: 주가, 주가등락률, 주가 연속상승, 주가 연속하락, 신고가, 신저가, 연속 상한가(국내), 연속 하한가(국내)
- **거래량/거래대금**: 거래량, 거래량 비율

#### 기술 필터
- 주가-이동평균선 돌파, 이동평균선 돌파, 이동평균선 배열
- 거래량이동평균선 돌파, 주가-볼린저밴드 돌파, RSI 범위

### 5.3 결과 테이블
- 순위, 종목 아이콘/이름, 현재가, 등락률, 카테고리, 시가총액, 거래량, 애널리스트 분석, 주가등락률
- 정렬 가능 (주가등락률 등)
- 필터 선택 시 tooltip으로 상세 수치 설정 가능 ("필터를 선택하면 자세한 수치를 설정할 수 있어요")
- 하단: 활성 필터 태그 + 초기화 + "N개 주식보기" CTA

## 8. 핵심 인사이트 요약

1. **토스증권의 강점은 "정보 밀도 + 접근성"**: 한 화면에서 차트, 호가, 주문, 커뮤니티를 동시에 볼 수 있는 3열 레이아웃이 핵심
2. **스크리너의 프리셋이 진입장벽을 낮춤**: 초보 투자자도 "연속 상승세" 같은 직관적 이름으로 종목 탐색 가능
3. **소셜 요소가 체류시간 증가**: 커뮤니티/피드가 정보 탐색 외의 사용 동기를 제공
4. **DI금융의 차별화 포인트는 "자동화"**: 토스증권이 수동 매매 중심인 반면, DI금융은 AI 자동매매 봇이라는 독보적 기능 보유
5. **UX 세부 사항이 신뢰도를 좌우**: 탭 타이틀 실시간 가격, 키보드 단축키, 실시간 데이터 등 사소한 디테일이 "전문가용 도구"라는 인상을 만듬
