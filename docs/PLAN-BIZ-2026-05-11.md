## 1. 시장 분석 + 경쟁 포지셔닝

### 1.1 한국 자동매매·퀀트 서비스 시장 (2026-05 기준)

한국 시장은 5개 레이어로 쪼개진다.

| 레이어 | 대표 서비스 | 특징 | Zepta 와의 거리 |
|---|---|---|---|
| **거래소 자체 봇** | 업비트/빗썸 자동주문, 토스증권 조건검색식 | 진입 쉬움, 신뢰도 높음, 사용자 기본 노출 | 우리가 못 이기는 영역 — 협업/연동만 가능 |
| **신호 텔레그램·디스코드** | 익명 운영자 다수, 월 5~30만원 구독 | 가격대 있음, but 검증 어려움, 사기 다수 | **우리가 정조준할 시장** (검증된 데이터 기반) |
| **B2C 자동매매 SaaS** | 쿼블, 위클리쿼블, 알고리즈마, 트레이딩뷰+Webhook | 한국형 UI, 백테스트 강조 | **직접 경쟁자** |
| **해외 글로벌** | 3Commas, Pionex, Cryptohopper, Bitsgap | 거래량 큰 시장, 영어 UI, 코인 only | 한국 시장에서 UX 갭이 큼 |
| **트레이딩뷰 + 봇 조합** | TV Alert → Webhook → 자체 봇 | 강력하지만 진입 장벽 높음, 월 $14~60 | 고급자 시장 — 우리 입문자 풀과 분리 |

### 1.2 경쟁사별 강·약점 (한 줄 요약)

- **쿼블 (qubl.io)**: 한국형 UI 가장 우수, 그러나 알파 R&D 약함, 전략 30개 미만. 가격 무료~월 4.9만원.
- **위클리쿼블**: 주식 백테스트 강함, but UI 노후, 자동매매 빈약.
- **3Commas**: 글로벌 1위, 가격 $29~99/월. UX 복잡, 한국어 미지원, 사용자 fatigue 누적 중.
- **Pionex**: 거래소 + 봇 통합. 진입 가장 쉬움 — but 봇 종류 16개로 한정, 알파 R&D 거의 없음.
- **트레이딩뷰**: 신호·차트 표준이지만 Webhook 설정·서버 구축은 사용자 몫. 진입 장벽 매우 높음.
- **빗썸/업비트 자체 봇**: 거래소가 직접 제공 → 사용자 가입 마찰 0. 그러나 단순 그리드·DCA 만 제공, **알파 제로**.

### 1.3 Zepta 의 USP (3~5개)

대표 자본 $370 인 매우 초기 단계지만, **자산은 명확하게 4가지**가 있다.

1. **24/7 알파랩 자동 R&D 시스템** (`api/agents/continuous-backtest.js`, `alpha-status.js`)
   → 경쟁사는 사람이 매뉴얼로 전략 업데이트, 우리는 **알고리즘이 직접 알파를 발굴·promote·demote**. 이건 글로벌에서도 매우 드문 자산. Pionex/3Commas 도 이걸 못한다.
2. **33개 알파 + 8개 strategy family + Hurst/엔트로피 등 학문 기반 알파**
   → 쿼블·트뷰 alerts·텔레그램 신호방은 RSI·MACD 정도. 우리는 정보흐름·마이크로스트럭처·엔트로피 레짐까지. **학문적 깊이**가 마케팅 카드.
3. **퀀트팀 2명 매일 KST 06:00 자동 스탠드업** (`api/agents/daily-standup.js`)
   → 이건 사용자에게 **운영 투명성**으로 직접 팔 수 있다. "매일 아침 분석가가 봇 상태를 보고합니다" — 텔레그램 신호방들이 가장 약한 지점.
4. **한국어 평어 + 입문자 친화 카피** (METRIC_HINTS 등)
   → 3Commas/Pionex 가 절대 못하는 부분. 토스/카카오페이 수준의 한국어 UX 는 명확한 차별점.
5. **무료 진입 + AdSense·쿠팡 보조 수익**
   → 한국 시장에서 "무료"는 강력한 트래픽 magnet. 단, **이게 USP 가 아닌 함정**이 될 수도 있음 (5장 참고).

### 1.4 약점·취약점 (포지셔닝 갭)

솔직한 평가:

- **A. 신뢰도 시그널 부족**: 운영 실적·실거래 결과 공개 채널이 없다. 신호방·쿼블은 "월간 수익률 공개" 로 신뢰를 쌓는데 우리는 아직 없음.
- **B. 사용자 → 사용자 의 관계가 0**: 카피트레이딩, 리더보드, 커뮤니티, 댓글 모두 부재. 결국 솔로 도구. 네트워크 효과 0.
- **C. 알파랩 = 개발자 화면**: 일반 사용자는 "Hurst 추세" 가 뭔지 모름. 우리 자랑이 사용자에게 안 닿음.
- **D. 한국 주식 직거래 부재**: 한국투자/키움 API 연동 없으면 **국내 사용자 가장 큰 풀** (KOSPI 거래자)을 못 잡음. 현재는 Alpaca(미국 주식) + Binance(코인)만.
- **E. 수익 모델 100% 광고**: AdSense + 쿠팡으로는 사용자 수익화가 ARPU 매우 낮음. MAU 10K 가 와도 월 30만원 수준 (`docs/traffic-strategy.md` 참고).

## 2. 수익 모델 전개

### 2.1 현재 상태

- **AdSense**: 등록 완료, 배너 노출
- **쿠팡 파트너스**: 도입 중
- **예상 수익 (MAU 기준)**: 1K → 1~3만원/월, 10K → 10~30만원/월

이건 트래픽이 100K MAU 가 되어야 의미 있는 수익. 그 전까지는 "**보조 수익 + 운영비 일부 충당**" 수준이다.

### 2.2 신규 수익 모델 후보

각 옵션 평가표:

#### (A) 구독 모델 — 월정액 Free / Pro / Premium

**핵심 가설**: 핀테크 사용자는 "데이터가 정말 좋으면 월 1~3만원은 낸다" (텔레그램 신호방 월 5~30만원이 이미 작동 중).

**3단 구조 제안**:

| 등급 | 가격 (월) | 포함 |
|---|---|---|
| Free | 0원 | 스크리너, 백테스트(일 5회), 봇 1개, 광고 노출 |
| Pro | 9,900원 | 봇 무제한, 백테스트 무제한, 알람 무제한, 광고 제거, 알파랩 leaderboard 접근 |
| Premium | 29,900원 | Pro + 카피트레이딩, API 액세스, 실시간 텔레그램 시그널, 신규 알파 우선 접근 |

- **예상 ARPU**: Pro 9.9K × 5% 전환율 = 사용자당 평균 495원/월 = MAU 10K 면 월 495만원 (현 AdSense 의 15~50배)
- **한국 법규 리스크**: **낮음** — 구독은 SaaS 표준 모델. 단, "투자 자문" 으로 해석될 표현 회피 필요 (자본시장법상 "투자 권유" 표현 X). "데이터 도구" 포지셔닝 유지.
- **도입 난이도**: **Medium** — Stripe/토스페이먼츠/포트원(아임포트) 연동 1~2주 + 권한 분기 1주.
- **추천 타이밍**: **MAU 1,000명 또는 일일 활성 사용자 100명 도달 후**. 그 전엔 무료 풀을 키우는 데 집중. **사용자 1000명 시점이 골든 윈도우**.

#### (B) 수수료 모델 — 거래량/수익 기반 share

**핵심 가설**: 봇이 사용자 수익을 만들면 그 일부를 share.

- **예상 ARPU**: 평균 사용자 봇 운영 자금 500달러 × 월 3% 수익 = 15달러 수익 → 우리 20% share = 3달러/월
- **한국 법규 리스크**: **매우 높음** ⚠️ — 자본시장법상 **투자일임업 / 투자자문업 인가 필요**. 인가 없이 수익 공유는 **불법**. 금융감독원 제재 대상.
- **도입 난이도**: **High** (법인화 + 인가 + 신탁 구조 필요)
- **추천 타이밍**: **MRR 3,000만원 / 사용자 5만명 이후**. 그 전엔 절대 손대지 말 것. 비교사례: 두물머리(불릴리오) 가 투자자문업 인가에 1~2년 소요. 우리 단계에선 위험 대비 수익 안 맞음.

#### (C) 데이터 판매 — 퀀트 시그널 B2B API

**핵심 가설**: 우리 알파랩에서 발굴된 시그널을 헤지펀드·자산운용사·다른 핀테크에 API 로 판매.

- **예상 ARPU**: 1개 클라이언트 월 100~500만원 (5~10개면 월 1,000만원~)
- **한국 법규 리스크**: **낮음** — "데이터 제공" 으로 포지셔닝하면 자본시장법 회피. "투자자문" 표현만 안 쓰면 됨.
- **도입 난이도**: **Medium** (API 게이트웨이 + 인증 + SLA 문서)
- **추천 타이밍**: **알파랩 6개월 운영 + Sharpe 1.5+ 시그널 3개 이상 검증 후**. 즉, **2026 Q3~Q4 적정 시점**. 그 전엔 trackrecord 가 약함.

#### (D) 교육 컨텐츠 — 강의·웨비나·구독

**핵심 가설**: 한국 핀테크 사용자는 "투자 공부" 욕구 매우 높음. 클래스101·인프런 가격대 (9.9만원~) 검증된 시장.

- **예상 ARPU**: 강의 1개 9.9만원 × 월 50명 = 월 495만원
- **한국 법규 리스크**: **낮음** — 교육은 "투자자문" 아님 명확. 단, "이 전략 따라하면 수익" 같은 보장 표현 X.
- **도입 난이도**: **Medium** (강의 제작 시간 큼, but 플랫폼 자체는 단순)
- **추천 타이밍**: **블로그 트래픽 일 1,000+ 도달 후**. 콘텐츠 자산이 강의 marketing 동력. 현재 블로그 11개 보유 → 30개 도달 후 시작 권장.

#### (E) 광고 다각화 — Naver·Kakao·기타

**핵심 가설**: AdSense 외에도 한국 광고 채널을 늘려 노출당 단가 향상.

- **Naver 광고 (네이버 디스플레이)**: 한국 사용자 CPC 가 AdSense 대비 30~50% 높음.
- **카카오 모먼트**: 카카오 사용자 풀 직접 도달.
- **DCO/DSP**: 모비온, NHN ACE 등 한국 토종 광고 네트워크.
- **예상 ARPU 향상**: 광고 영역당 1.3~1.5배.
- **한국 법규 리스크**: 0
- **도입 난이도**: **Low** (각 광고 ID 발급 + 스크립트 삽입)
- **추천 타이밍**: **즉시**. 단, 광고 영역이 너무 많아지지 않도록 UX 검증 병행. 광고 슬롯 최대 3개 권장.

#### (F) 제휴·어필리에이트 확대 — 증권사·거래소 referral

**핵심 가설**: 이미 사용자가 "Binance/Alpaca 연결" 단계를 거치므로, **referral 코드 삽입이 자연스러움**.

- **Binance Referral**: 거래 수수료 20~40% 평생 share. 사용자당 월 평균 1~5달러 수익.
- **Bybit/OKX**: 비슷한 구조, 한국 OFAC 제재 외 사용자 대상.
- **국내 증권사**: 키움 / 토스증권 / 미래에셋 — 신규 계좌 개설당 1~5만원. **현재 한국 주식 연동 없으니 우선 검토**.
- **거래소 비교 페이지**: "어떤 거래소를 써야 할까?" 콘텐츠 → 어필리에이트 자연스럽게.

- **예상 ARPU**: 사용자당 월 1~3달러 (코인 활성 사용자 기준)
- **한국 법규 리스크**: **낮음~중간** — referral 공개 표기 필수 (공정거래위원회 광고 표시 규정).
- **도입 난이도**: **Low** (코드 삽입 + 콘텐츠 제작)
- **추천 타이밍**: **즉시**. Binance 연결 페이지에 referral 적용이 1주일 이내 가능.

### 2.3 추천 수익 모델 로드맵 (시간 순서)

## 3. 신규/개선/고도화 피처 후보 — 우선순위 매트릭스

평가 공식: **우선순위 점수 = (사용자 임팩트 × 수익 임팩트) / 개발 난이도**

### 3.1 개선 (existing 보강)

| 피처 | 사용자 임팩트 | 난이도 | 수익 임팩트 | 점수 | 한 줄 설명 |
|---|---|---|---|---|---|
| **봇 운영 리포트 페이지** | 5 | 2 | 5 | **12.5** | 매주 봇별 수익/거래/Sharpe 공개 → 신뢰도 자산 형성 |
| **스크리너 즐겨찾기 + 알람 연동** | 5 | 2 | 4 | **10.0** | 사용자가 발견한 조건을 저장·알림으로 받으면 리텐션 폭증 |
| **AlphaLab → 사용자 친화 카피로 번역** | 4 | 1 | 4 | **16.0** | "Hurst 추세" → "지금 시장은 한 방향 흐름" — 큰 자산 unlock |
| **포트폴리오 리밸런싱 시뮬레이션** | 4 | 3 | 3 | **4.0** | 현재 포트폴리오 → 추천 비중 비교 시각화 |
| **블로그 카테고리·태그·검색** | 3 | 1 | 3 | **9.0** | SEO 트래픽 향상, 콘텐츠 발견성 ↑ |
| **알람: 가격·신호·뉴스·임계값** | 5 | 3 | 4 | **6.7** | 텔레그램 push → 리텐션 강화 |

### 4.1 현재 funnel + dropout 가설

```
[랜딩] → [가입] → [이메일 인증] → [Binance/Alpaca 연결] → [봇 활성화] → [실거래] → [1주 retention]
   ?  ↘ 70%      ↘ 30%            ↘ 50%                  ↘ 40%        ↘ 30%        ↘ 20%
```

각 단계 dropout 가설 + 해결 idea:

| 단계 | dropout 가설 | 해결 idea |
|---|---|---|
| **랜딩 → 가입** | "뭐 하는 사이트인지 즉시 이해 안 됨", "신뢰 시그널 부족" | 히어로에 봇 운영 실적 carousel, "5초 가입 → 봇 활성화" 메시지 |
| **가입 → 이메일 인증** | 이메일 못 받음, 스팸함, 사용자 피로 | 인증 이메일 도착시간 명시, "스팸함 확인" 안내, OAuth(구글) 추가로 1-tap 가입 |
| **이메일 인증 → 거래소 연결** | "API 키 발급" 진입 장벽, 두려움 | **페이퍼 트레이딩 모드 default** — 실거래 연결 없이도 봇 사용 가능 (이미 있음, 강조 부족) |
| **거래소 연결 → 봇 활성화** | "어떤 봇 골라야 할지 모름" | 봇 추천 wizard (3개 질문 → 1개 추천) |
| **봇 활성화 → 실거래** | 작은 자본으로 결과 안 보임 | 봇 첫 거래 알림(축하), 첫 주 시뮬 리포트 |
| **실거래 → 1주 retention** | 매일 들어올 이유 없음 | 일일 텔레그램 보고, 주간 이메일 리포트, push 알림 |

### 4.2 리텐션 메커니즘

이미 있는 자산:
- 일일 KST 06:00 자동 스탠드업 (텔레그램)
- 홈 화면 스트릭(streak) 시스템 ("🔥 N일 연속")
- 알람 시스템 (telegram-send)

**추가 권장**:
1. **주간 이메일 리포트**: 매주 일요일 — 내 봇 수익률, 추천 신규 봇, 시장 정리 (보낸 첫 주 retention +15% 흔함)
2. **Push 알림 (PWA)**: 큰 시장 이벤트, 봇 신호, 가격 임계값
3. **Gamification**: 봇 활성화 N일 → 뱃지, 첫 수익 → 축하 모달, 첫 손실 → "괜찮아요" 메시지
4. **카피트레이딩 알림**: "내가 따라가는 봇이 거래 했어요" — 매우 강력한 retention hook
5. **블로그 댓글 / 좋아요**: 콘텐츠 engagement → 재방문 유도

- **예상 사용자 임팩트**: 매우 큼 — Pionex 의 leaderboard 가 사용자 가장 큰 hook
- **예상 분량**: M (2주)
- **실행 방법**:
  - 익명 닉네임 + 30일 수익률 + Sharpe + MDD 순위
  - 필터: 봇 종류 / 자산 (주식/코인) / 기간 (7일/30일/90일)
  - Top 10 매주 자동 텔레그램 공지 → 사용자 재방문 hook
  - opt-out 가능 (default opt-in 권장, but 한국 개인정보 민감도 고려 opt-in 안전)

### #4. 스크리너 즐겨찾기 + 알람 연동

**1줄 핵심 가치**: 발견한 조건을 저장하고 조건 만족 시 텔레그램 알림 → 매일 들어올 이유 생성.

- **화면 변경 범위**: existing 보강 (스크리너 화면에 "조건 저장" 버튼 + 마이페이지에 "저장한 조건" 섹션)
- **데이터 모델 변경**: Supabase `saved_screeners` 테이블 (user_id, name, conditions JSON, alert_enabled bool)
- **예상 매출 임팩트**: 리텐션 +20%, Pro 구독 hook ("저장 무제한")
- **예상 사용자 임팩트**: 큼 — 매일 들어올 이유 생성
- **예상 분량**: S (1주)
- **실행 방법**:
  - Free: 3개 조건 저장, Pro: 무제한
  - 알람: 조건 매칭 종목 발생 시 텔레그램 + 이메일
  - 검증된 패턴 4개 사전 제공 ("RSI 30 이하 + 거래량 급증", "골든크로스 직전" 등)

### #5. DCA 자동매매 (정기 매수 봇)

**1줄 핵심 가치**: 입문자 가장 안전한 진입 경로. Pionex hit feature 직접 카피.

- **화면 변경 범위**: existing 보강 (AutoTrading 의 봇 리스트에 DCA 봇 1개 추가) + 설정 모달
- **데이터 모델 변경**: `bots` 테이블에 DCA 설정 (frequency, amount, symbol)
- **예상 매출 임팩트**: 입문자 활성화율 +30%, Free → Pro 전환 hook (DCA 봇 1개 Free / 5개 Pro)
- **예상 사용자 임팩트**: 매우 큼 — 진입 장벽 가장 낮음
- **예상 분량**: S~M (1~2주)
- **실행 방법**:
  - 설정: 종목 (BTC/ETH/SOL/AAPL/TSLA 등) + 금액 + 주기 (매일/매주/매월) + 시간
  - Binance/Alpaca 정기주문 API 활용
  - 실거래 + 페이퍼 트레이딩 모두 지원
  - Pro: 다중 종목 DCA + 변동성 적응형 (큰 하락 시 평균보다 많이 매수)
