# Toit 유입 전략 & 광고 실행 가이드

## 1. SEO (검색엔진 최적화) — 이미 적용된 사항

- `robots.txt` + `sitemap.xml` 생성 완료
- JSON-LD 구조화 데이터 (WebApplication + FinancialService)
- Open Graph / Twitter Card 메타 태그 강화
- 캐노니컬 URL + hreflang 설정

### 추가 실행 항목

| 항목 | 액션 | 우선순위 |
|------|-------|---------|
| Google Search Console | https://search.google.com/search-console 에서 사이트 등록 후 sitemap.xml 제출 | 즉시 |
| Naver 웹마스터 도구 | https://searchadvisor.naver.com 등록 및 사이트맵 제출 | 즉시 |
| og:image 실제 이미지 | 1200x630px 프리뷰 이미지 제작 → `/public/og-image.png` 배치 | 1주 내 |
| 블로그 콘텐츠 | 네이버 블로그 + 티스토리에 "AI 퀀트 자동매매" 키워드 글 발행 | 주 2회 |
| 백링크 | 투자 커뮤니티(클리앙, 뽐뿌, 디시 주식갤) 자연스러운 노출 | 지속 |

## 2. 콘텐츠 마케팅 전략

### 핵심 키워드 (한국어)
- 주식 자동매매, AI 퀀트 전략, 비트코인 자동매매
- 주식 스크리너, 코인 스크리너, 무료 투자 도구
- 퀀트 투자, 알고리즘 트레이딩, 페이퍼 트레이딩

### 콘텐츠 유형
1. **교육 콘텐츠**: "퀀트 투자 입문 가이드", "RSI·MACD로 매매 타이밍 잡기"
2. **실적 리포트**: 매주 봇 운영 실적 공개 (수익률, 거래 횟수, 승률)
3. **비교 콘텐츠**: "Toit vs 키움증권 조건검색 비교", "무료 스크리너 TOP 5"
4. **튜토리얼**: 봇 설정법, 알파카 API 연동 방법 영상/글

### 채널별 전략
- **네이버 블로그**: 검색 유입 메인 채널, 주 2~3회 발행
- **유튜브**: 봇 운영 실적 리뷰 + 퀀트 전략 해설 (월 2~4회)
- **디스코드/텔레그램**: 커뮤니티 구축, 시그널 공유
- **트위터(X)**: 일일 매매 시그널 자동 포스팅

## 3. 쿠팡 파트너스 광고 최적화

### 현재 상태
- 쿠팡 파트너스 SDK 로드 완료 (`g.js`)
- 캐러셀 배너 (id: 975402) 배치 완료

### 최적화 방안
1. **배치 위치**: 홈 하단, 스크리너 결과 하단, 블로그 콘텐츠 사이드바
2. **카테고리 타겟팅**: 투자 서적, 모니터(트레이딩용), 컴퓨터 주변기기
3. **시즌 캠페인**: 연말 결산, 새해 투자 관련 상품 추천

## 4. Google AdSense 실행

### 준비 사항
1. `index.html`의 `ca-pub-XXXXXXXXXXXXXXXX`를 실제 AdSense ID로 교체
2. AdSense 승인 조건: 유효 콘텐츠, 개인정보처리방침, 사이트맵
3. 개인정보처리방침 페이지 필요 → `/privacy` 라우트 추가 권장

### 배치 전략
- 헤더 하단 리더보드 (728x90)
- 스크리너 결과 사이에 네이티브 광고
- 모바일은 인터스티셜 회피 (UX 유지), 배너형 위주
