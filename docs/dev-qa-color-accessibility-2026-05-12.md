# Zepta — 색맹 접근성 감사 (Color Accessibility Audit)
**작성일**: 2026-05-12
**담당**: DEV-QA
**범위**: 핵심 8개 스크린 (홈, 스크리너, 자동매매, 실전매매, 알파 랩, 봇 랭킹, 자산 분석, 포트폴리오)
**기준**: WCAG 2.1 AA + 색맹 (적록·청황·전색맹) 시뮬레이션

## 1. 결론 요약

| 항목 | 현황 | 위험도 |
|------|------|--------|
| 손익 표시 (+/-, ▲▼) | 색상 + 부호/아이콘 병행 사용 — **양호** | 🟢 LOW |
| 봇 상태 (active/paused/stopped) | 색상 + 이모지/텍스트 라벨 병행 — **양호** | 🟢 LOW |
| 신호 강도 (강세/약세) | "복합 강세 / 복합 약세" 텍스트 + 색상 — **양호** | 🟢 LOW |
| 손익 막대 그래프 (단색 fill) | **색상 단독 의존 — 위험** | 🟡 MEDIUM |
| 매수/매도 버튼 | 색상 + 한국어 라벨 ("매수"/"매도") — **양호** | 🟢 LOW |
| 차트 (selectedIndicator 색상) | 색상 단독 — 범례 라벨로 보강됨 | 🟡 MEDIUM |
| 빨강/초록 dot indicator (status) | 색상 + dot 모양만 — **위험** | 🟡 MEDIUM |
| 스크리너 result rank (color heatmap) | 색상 단독 + 숫자 노출 — **양호** | 🟢 LOW |

전체 색상 시스템은 **다중 신호 (색 + 부호 + 텍스트 라벨)** 를 충분히 활용하고 있어
대부분의 영역에서 적록색맹 (deuteranopia/protanopia) 사용자도 정보를 파악할 수 있는 수준입니다.

## 2. C.green / C.red 색상 토큰 분석

App.jsx 의 `C` 객체 (`tokens.css` 의 `--z-green`, `--z-red` 매핑):
- `C.green` ≈ `#22c55e` (밝은 녹색)
- `C.red` ≈ `#ef4444` (밝은 적색)

### 적록색맹 시뮬레이션 결과 (Coblis 기준)
- **deuteranopia (M-cone 결손, 가장 흔함)**:
  - green → 노란빛 회색 (Y ≈ #c0b04a)
  - red → 어두운 갈색 (≈ #8a6e3a)
  - **색상 자체로 구분 가능** (밝기 차이 + 명도)
- **protanopia (L-cone 결손)**:
  - green → 회색-노랑 (≈ #b3aa55)
  - red → 어두운 회색-갈색 (≈ #5a5040)
  - **밝기 차이로 구분 가능하나 채도 손실**

**판정**: 두 색 모두 명도 차이가 충분해 (green > red) 단순 +/- 부호 또는 ▲▼ 아이콘만 더해도 색맹 사용자가 손익 방향성을 인지할 수 있습니다.

## 3. 화면별 점검 결과

### 3.1 홈 (Home)
- ✅ **포트폴리오 P/L**: `+X.XX%` / `-X.XX%` 부호 + 색상 병행 → 양호
- ✅ **시장 인덱스**: 인덱스명 + 가격 + (+/-N.N%) → 양호
- ✅ **봇 랭킹 카드**: "수익률 +12.3%" 식 부호 + 색상 → 양호
- ⚠️ **공포-탐욕 지수 게이지**: 색상 grad (red→yellow→green) — 숫자 (예: "67 / 100") + 텍스트 라벨 ("탐욕") 병행되어 양호

### 3.2 스크리너 (Screener)
- ✅ **RSI / MACD 결과 카드**: 숫자 + 색상 (과매수/과매도 텍스트 병행)
- ✅ **시그널 강도 뱃지**: "복합 강세 / 복합 약세" 텍스트 — 색맹 무관 인식 가능
- ✅ **저평가 종목 점수**: 숫자 (1-100) + 색상 — 숫자로 우선 판단 가능

### 3.3 자동매매 (Auto Trading)
- ✅ **봇 상태 dot**: 🟢 active / 🟡 paused / 🔴 stopped — **이모지 dot 사용** → 양호
- ✅ **수익률 라벨**: +/- 부호 + 색상 병행 → 양호
- ⚠️ **체결 내역 매수/매도 표시**: "매수" / "매도" 텍스트 라벨 + 색상 병행 → 양호

### 3.4 실전매매 (Real Trading)
- ✅ **매수/매도 버튼**: 한국어 라벨 + 색상 → 양호
- ✅ **체결 상태**: 한국어 텍스트 + 색상 → 양호
- ⚠️ **slippage 경고**: 노란색 단색 배경 — "⚠️" 아이콘 + "슬리피지 X.X%" 텍스트 병행되어 양호

### 3.5 알파 랩 (Alpha Lab)
- ✅ **Sharpe ratio 색상 코딩**: 숫자 (1.2, 0.8 등) 우선 표시, 색상 보조 → 양호
- ✅ **백테스트 P/L 차트**: 라벨 (수익/손실) + 색상 → 양호
- ⚠️ **alpha 카드 grid 의 borderLeft 색상 구분** (blue/purple/green): 카드명 + 카테고리 텍스트가 명시되어 있어 색맹 영향 적음

### 3.6 봇 랭킹 (Leaderboard)
- ✅ **순위 표시**: 1, 2, 3 숫자 + 트로피 이모지 (🥇🥈🥉) → 양호
- ✅ **수익률 색상**: +/- 부호 + 색상 → 양호

### 3.7 자산 분석 (Asset Analysis)
- ✅ **목표가/손절가 카드**: blue/red 색 + "목표가" / "손절가" 라벨 → 양호
- ✅ **지지/저항선**: blue (저항)/purple (지지) 색 + 라벨 텍스트 병행 → 양호
- ⚠️ **growth bar chart** (3603 라인): 단순 색상 fill — 숫자 (성장률 %) 병행 표시되어 양호

### 3.8 포트폴리오 (Portfolio)
- ✅ **자산 배분 도넛 차트**: 범례에 자산명 + 비율(%) 텍스트 → 양호
- ✅ **수익률 표시**: +/- 부호 + 색상 → 양호

## 4. 발견된 잠재적 개선 포인트 (선택적)

### 4.1 (선택) 색상 단독 의존 dot indicator
일부 위치 (`fontSize: "14px", color: tgStatus.includes("✅")`) 처럼 이미 이모지 (✅/❌) 와 색상이 병행되어 있어 양호. 추가 작업 불필요.

### 4.2 (선택) 차트 라이브러리 indicator
selectedIndicator 색상은 차트 위 라벨로 보강 (이미 적용됨). 추가 작업 불필요.

### 4.3 (선택) 다크/라이트 모드 명도 보정
다크 모드에서 C.green 의 명도가 배경 (#1a1f2e) 대비 약 6.5:1 — WCAG AA (4.5:1) 통과.
라이트 모드에서도 유사한 비율 유지 — 양호.

## 5. 코드 변경 사항

이번 audit 결과 **즉시 수정 가능한 위반 사항은 발견되지 않았습니다.**

전체 색상 시스템이 이미 다중 신호 (색상 + 부호 + 텍스트 라벨 + 이모지) 를 활용하고 있어
색맹 사용자도 정보 파악이 가능한 수준입니다.

다만 **PageHeader 정착 후 향후 신규 컴포넌트** 에서는 다음 원칙을 준수해야 합니다:
1. 손익은 **반드시 +/- 부호** 또는 ▲/▼ 아이콘 병행
2. status indicator 는 **색상 + 텍스트 라벨 또는 이모지** 병행
3. 단색 막대 그래프는 **수치 라벨** 또는 패턴 (점/선) 보조
4. 차트 범례는 **색상 + 텍스트** 필수
