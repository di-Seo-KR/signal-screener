# Zepta 화면 설계서 v3 — IA 개편 (2026-08-12 대표 지시)

> 목적: 서비스 기획·디자인·구현이 공유하는 단일 설계 문서.
> 각 화면의 플로우·구역·컴포넌트·데이터 배선·상태를 정의한다.
> 디자인 토큰·컴포넌트 문법은 디자인 시스템 v2(퍼플, Zepta Design System.dc.html)를 따른다.

## 0. IA 변경 요약

> ★ 2026-08-12 개정 (대표 결정): "시그널 탭 + 주식 탭" 구조는 주식 시그널이 두 곳에
> 중복되는 문제가 있어, **자산군 이원화(코인 탭 / 주식 탭)**로 확정한다.

| 탭 | 변경 전 | 변경 후 (v3 확정) |
|---|---|---|
| 홈 | 요약 대시보드 (텍스트 링크 다수) | 유지하되 **섹션 경계 시각 구분 + 액션 버튼 컴포넌트화** |
| 뉴스 | 뉴스 피드 | **코인** — 코인 시그널 + 코인 지표(김프·펀딩·OI·롱숏·24h 청산·온도) |
| 시장 | 통합 스크리너 (버튼 과다, 주식 중심) | **주식** — 주식 시그널 + 스크리너 간소화 재편 |
| 지표 | 지표 허브 (게이지+진입점 그리드) | **지표** — 경제 캘린더 + 뉴스 재구성 |
| MY | 프로필 (구성 빈약) | **MY 리뉴얼** — 프로필·설정·활동·owner 콘솔 진입 |

하단 탭: **[홈 · 코인 · 주식 · 지표 · MY]**. 코인/주식 비교는 홈의 '오늘의 시그널'
[코인|주식] 미리보기 토글이 담당(전체 보기 → 각 자산군 탭으로).

- 기존 지표 허브의 게이지들 → 시그널 탭(코인 지표 구역)과 홈 스냅샷으로 분산 흡수.
- 기존 /coin 정적 대시보드의 역할 → 시그널 탭이 대체 (SEO 페이지 자체는 유지).
- 자동매매 콘솔: owner 전용 유지 (`isOwner` 게이트 검증 완료), UI 리뉴얼 대상.

## 1. 홈 — "오늘 시장을 30초에"

**플로우**: 부트 스플래시 → 홈. 각 섹션은 해당 전용 탭으로의 진입점(미리보기 3~4개 + 더보기).

**구역** (위→아래):
1. 인사 + 시장 헤드라인 + 알림 버튼
2. 지수 스트립 (6지수 가로 스크롤, 카드 탭 → 차트 모달)
3. 오늘의 시그널 미리보기 — [코인|주식] 세그먼트, 카드 3개, "전체 보기" → **코인/주식 탭** (활성 세그먼트 따라)
4. 톱 뉴스 3행 → **지표 탭(뉴스 서브탭)**
5. 경제 캘린더 미리보기 (다가오는 고중요 2~3건) → **지표 탭(캘린더 서브탭)**
6. 지표 스냅샷 (공포탐욕·마켓 온도 게이지 2개) → 코인 탭 컨텍스트 구역
7. 관심종목 (로그인 시)
8. 면책

**개선 요구 (대표 지시)**:
- 섹션 = 카드 컨테이너로 명확히 구분 (배경/보더/간격으로 경계 — 현재는 제목만 떠 있음)
- "새로고침", "전문 보기 →" 등 텍스트 링크 → **버튼/칩 컴포넌트** (배경·보더 있는 터치 타깃)
- 섹션 헤더 규격 통일: 제목 + (LIVE 도트) + 우측 액션 버튼 1개

**데이터**: 기존 배선 유지 (marketIndices, coin/stock-scores, news KV, econ-calendar, fearGreed, watchlist).

## 2. 코인 탭 (구 뉴스 자리) — 코인 시그널 + 코인 지표

**목적**: "코인 시장 지금 상태 + 어떤 코인에 신호가 있나"의 단일 목적지. 구 /coin 대시보드 대체.

**플로우**: 홈 시그널 미리보기(코인) "전체 보기" / 하단 탭 → 코인. 카드 탭 → 종목 상세 시트.

**구역**:
1. 시장 컨텍스트 스트립 — 마켓 온도·공포탐욕·김프·펀딩 평균 미니 카드 4개 (탭 → 확장 시트)
2. 파생·온체인 바 — OI 24h·글로벌 롱숏·**24h 청산 요약**(롱/숏 청산 비중 게이지, Coinalyze 실데이터)·스테이블 추세
3. 시그널 카드 리스트 (score 내림차순, 전 유니버스 ~50)
4. 신선도 캡션 (실측 ts) + 면책
- 청산 **맵**(가격대 클러스터)은 데이터 소스 확보 전 — 24h 청산 "요약"까지만 (가짜 데이터 금지).

**데이터**: coin-scores(oc 포함)·indicators/summary(김프·펀딩)·market-temp. 전부 기존 엔드포인트.

**상태**: 풀 미적재 시 빈 상태(점선), 부분 실패는 해당 카드만 생략.

## 3. 주식 탭 — 주식 시그널 + 스크리너 (간소화)

**목적**: 주식 탐색 전용. "버튼 과다" 해소가 핵심.

**플로우**: 진입 → 프리셋 결과 즉시 표시(제로 클릭) → 조건 조정은 시트로.

**구역**:
1. 헤더: 제목 + 마지막 스캔 시각
2. **프리셋 칩 한 줄** (가로 스크롤 5~6개: 상승 신호·급등·과매도 반등·거래량 급증·관심 조건) — 현재의 버튼 그리드 전면 대체
3. "조건 편집" 버튼 1개 → **바텀 시트**로 상세 조건 (현재 인라인 details 패널 대체 — 화면 점유 제거)
4. 결과: 데스크탑 테이블 / 모바일 카드 (1f 문법 유지), 정렬 헤더
5. 상단: **주식 시그널 리스트** (stock-scores 전체 — 미국/한국 필터 칩, 장 상태 배지 + dataTs).
   스크리너와 한 화면: 상단 시그널 / 하단 "조건으로 찾기"(스크리너). 주식 시그널의 유일한 위치.

**삭제/이동**: 코인 관련 필터·진입점은 코인 탭으로 이동. 저장한 조건은 MY 로.

## 4. 지표 — 캘린더 + 뉴스

**목적**: "시장 일정과 소식"의 단일 목적지.

**구역**: 상단 서브탭 [캘린더|뉴스] (딥링크: /indicators?view=news)
- **캘린더**: 주간 날짜 스트립 + 이벤트 행(중요도·예측/이전/발표) + 펼침 해석 — 기존 1c 구현 이식
- **뉴스**: 기존 1d 뉴스 피드 이식 (카테고리 칩·감성 필터·타임라인)
- 기존 지표 허브의 게이지 그리드는 폐지 — 게이지는 코인 탭·홈 스냅샷이 흡수. `/index/*` SEO 페이지는 유지(진입 링크는 코인 탭 컨텍스트 카드에서).

## 5. MY — 리뉴얼

**구역**:
1. 프로필 헤더: 아바타·닉네임·이메일 / 비로그인: 가입 CTA 카드
2. 활동 스탯 3열 (관심종목·저장 조건·연속 접속)
3. 바로가기 리스트: 관심종목 관리 / 저장한 스크리너 조건 / 알림 설정
4. 설정: 테마(다크/라이트) · 언어(한/영) 토글 — **최초로 UI 노출**
5. (owner 전용) "매매 콘솔" 진입 카드 — 일반 사용자에겐 미렌더
6. 고객지원 리스트 + 로그아웃 + 버전

**버그 수정 완료**: 탭 전환 시 스크롤 위치 잔존(iOS 모멘텀) → 커밋 후 최상단 고정 이중화.

## 6. 차트 모달 — 리뉴얼 (디자인 요청 대상)

**현행 문제**: 자체 캔들차트 + 컨트롤이 구식, 헤더 잡다.
**요구**: 헤더(심볼·현재가·등락 알약·닫기) / TF 칩 한 줄 / 캔들+거래량 / 타이밍 마커(▲▼) 유지 /
지지·저항 밴드 오버레이 토글 / 하단 요약 배지(신호 상태·주요 레벨 거리). 다크/라이트.

## 7. 자동매매 콘솔 (owner 전용) — 리뉴얼 (디자인 요청 대상)

**게이트**: `isOwner`(이메일 판정) — 전 매매 탭 검증 완료. 비owner 는 렌더 자체가 없음.
**요구**: ① 상태 히어로(가동/킬스위치·총자산·일 손익) ② 포지션 카드(방향 보더·미실현 손익·SL/트레일 거리)
③ 시그널 큐(엔진이 보는 상위 후보) ④ 봇별 성과 스트립 ⑤ 최근 체결 타임라인 ⑥ 리스크 패널(노출·쿨다운·가드 상태).
전부 기존 실데이터 배선 재사용 — 신규 수치 발명 금지.

## 8. 공통 규칙

- **i18n**: v3 구현 배치에서 잔여 하드코딩 전량 t() 이관 (ko/en 패리티 검사 CI 수준으로).
- 상태 3종(로딩 스켈레톤/빈/에러+재시도) 전 화면 의무. 가짜 데이터·죽은 버튼 금지.
- 표현 3원칙. 접근성: AA 대비·키보드·aria (감사 기준 유지).
- 라우트: 기존 URL 유지 + 리다이렉트(/news → /crypto, /screener → /stocks 등), sitemap 동기화.
