Binance API 키 발급 가이드 — 자동매매 안전 셋업

2026년 5월 9일 · 실전 가이드 · 8분 읽기

자동매매를 시작하려면 Binance 거래소가 봇의 매수·매도 명령을 받을 수 있도록 API 키를 발급해야 합니다. 단순한 작업이지만 보안 설정 한 두 가지만 잘못 잡으면 자산이 노출될 수 있어요. 이 가이드는 처음 발급하시는 분도 안전하게 마칠 수 있도록 단계별로 정리했습니다.

왜 API 키가 필요한가

API 키는 "이 외부 프로그램에 내 계정 일부 권한을 위임한다" 는 일종의 출입증입니다. 자동매매 봇이 이 키로 시세를 조회하고 매수·매도 주문을 보냅니다. 비밀번호와 다른 점은 권한을 세밀하게 제한할 수 있다는 것 — 예를 들어 "출금은 절대 못 함" 으로 잠가둘 수 있습니다.

단계별 발급 절차

1단계

Binance 계정 보안 강화 (필수)

API 키 만들기 전에 2단계 인증 (2FA) 활성화 필수. Google Authenticator 또는 SMS. SMS 보다 Authenticator 앱이 안전합니다. 이 안 켜져 있으면 API 키 발급 자체가 막혀요.

2단계

API Management 페이지 접속

Binance 메인 → 우상단 프로필 → "API Management" 또는 한국어 메뉴에서 "API 관리" 클릭. 직접 URL: www.binance.com/en/my/settings/api-management

3단계

새 API 키 만들기

"Create API" 버튼 → "System generated" 선택 → 라벨 입력 (예: zepta-bot). 2FA 코드 입력하면 발급. 이때 "Secret Key" 가 한 번만 표시됨 — 안전한 곳에 저장. 닫으면 다시 못 봅니다.

4단계

권한 설정 — 중요!

발급 후 권한 설정 화면 진입. 다음 3개만 켜시고 나머지는 절대 끄세요:

  • ✅ Enable Reading (시세·잔고 조회)
  • ✅ Enable Futures (Futures 거래 — 자동매매 핵심)
  • ❌ Enable Withdrawals (출금) — 반드시 OFF. 봇이 자산 빼가는 사고 방지.
  • ❌ Enable Internal Transfer (내부 이체) — OFF 권장.
5단계

IP 화이트리스트 (강력 추천)

"Restrict access to trusted IPs only" 체크 → Zepta 같은 서비스에서 안내하는 IP 입력. IP 제한 설정하면 키가 유출돼도 다른 IP 에서는 사용 불가 → 보안 결정적 향상.

Zepta 사용 시: 자동매매 페이지에서 화이트리스트 IP 자동 안내. 그대로 복붙하면 됩니다.

6단계

키를 봇에 등록

Zepta → AI 매매 → "Binance 연결" → API Key + Secret Key 입력. 둘 다 AES-256 암호화로 저장됩니다. 평문 저장 안 함.

흔한 실수 5가지

  1. 출금 권한 켜고 발급 — 봇이 출금할 일 없습니다. 무조건 OFF.
  2. Secret Key 화면 닫고 메모 안 함 — 다시 못 봐요. 닫기 전에 안전한 곳에 저장.
  3. 스크린샷으로 키 보관 — 클라우드 동기화로 유출 위험. 1Password / Bitwarden 같은 비밀번호 매니저 추천.
  4. IP 화이트리스트 안 함 — 키 유출 시 즉시 자산 위험. 반드시 설정.
  5. Spot Trading 만 켜고 Futures 안 켬 — 자동매매는 Futures 필요. 권한 다시 확인.
⚠️ 보안 핵심: API 키 + Secret Key 는 비밀번호와 동급 으로 다루세요. 카카오톡 / 이메일 / 메신저로 절대 보내지 마시고, 의심스러운 사이트에는 입력 금지. Zepta 같은 정식 서비스도 키 등록 외에는 절대 다시 묻지 않습니다.

자동매매 시작 — 안전 권장 단계

키 등록 후 바로 큰돈 넣지 마시고 다음 순서 권장:

  1. Shadow 모드 2~4주 — 가짜 돈으로 봇이 어떻게 동작하는지 관찰
  2. $100~500 소액 시작 — 첫 1~2주 작은 금액으로 실거래 검증
  3. 점진적 증액 — 신뢰 쌓이면 단계적으로 늘림
  4. 안전잠금 즉시 차단 가능 — 이상하면 한 번 클릭으로 봇 정지

API 키 등록부터 자동매매 시작까지 한 화면에서 끝내세요. 안전 가이드 자동 안내.
