퀀트 전략 33가지, 한눈에 정리

2026년 5월 9일 · 전략 카탈로그 · 10분 읽기

퀀트 전략은 보통 4가지 패밀리로 나뉩니다. 추세추종(가격이 한 방향으로 움직이는 걸 따라가기), 평균회귀(과매수·과매도면 반대 베팅), 돌파(저항·지지 깨질 때 진입), 변동성(시장 변동성 자체를 거래). 어떤 전략이든 이 4가지 중 하나에 속합니다. 시장 국면이 바뀌면 잘 통하는 패밀리도 바뀌는데, 이 글에서 각 패밀리가 언제 강하고 언제 약한지 정리합니다.

추세추종 (Trend Following)

가격이 한 방향으로 움직이는 걸 따라가는 전략

대표 지표: 이동평균 교차, ADX, Donchian Channel, Supertrend, MACD Cross, Ichimoku.

대표 전략: SMA Cross / EMA Ribbon / 200일선 위 / Donchian 20-day / Turtle 20일 / Supertrend / MACD Cross / ADX Trend / Channel Breakout / Triple Screen

잘 통할 때: 큰 추세장 (Hurst > 0.55). 비트코인 강세장, 메가캡 주도 시장.
안 통할 때: 박스권. 추세 false signal 로 fakeout 자주 맞음.
평균회귀 (Mean Reversion)

가격이 평균에서 벗어나면 다시 돌아온다는 가정

대표 지표: RSI, 볼린저밴드, Stochastic, Z-Score, Williams %R, 이격도.

대표 전략: RSI 30/70 / BB Bounce / Stoch K%D / Z-Score Pair / Williams %R / Pairs Trading / Distance from MA / Daily Reversal / Overnight Gap Fade / Quintile Reversal

잘 통할 때: 박스권 (Hurst < 0.45). 변동성은 있지만 큰 방향 없음.
안 통할 때: 강한 추세장. RSI 70 넘어도 더 올라가는 경우 손실.
돌파 (Breakout)

중요 가격대를 깰 때 진입

대표 지표: 20/52주 신고가, 볼린저밴드 폭 압축 후 돌파, ATR 갑자기 증가, 거래량 급증.

대표 전략: 20-day High Breakout / 52-week High / BB Squeeze Breakout / Volume Spike / Range Break / Opening Range Breakout / Pivot Point / Darvas Box / NR4-NR7 / Inside Bar

잘 통할 때: 변동성 압축 후 폭발. 펀더멘털 변화 시작 시점.
안 통할 때: false breakout 많음. 특히 거래량 미동반 시.
변동성 (Volatility)

시장 변동성 자체를 거래 대상으로

대표 지표: ATR, VIX, Realized Volatility, GARCH, Volatility Clustering, Funding Rate.

대표 전략: ATR Position Sizing / VIX Regime / Vol Clustering / Hurst Filter / Entropy Detection / Funding Rate Carry / Microstructure / Information Flow / Order Flow Imbalance / Realized Vol Targeting

잘 통할 때: 다른 모든 전략의 보조. 포지션 사이징과 리스크 관리에 핵심.
안 통할 때: 단독으로 진입 신호 만들기엔 부족. 항상 다른 전략의 필터로 사용.

실전 운영의 핵심 — 멀티 전략 조합

한 전략만 고집하면 그 전략이 안 통하는 시기에 큰 손실 납니다. 보통 3~5개 전략을 시장 국면별로 가중치를 다르게 두고 조합하는 게 정석입니다. 추세장에서는 추세추종 가중치 70%, 박스권에서는 평균회귀 가중치 60% 이런 식.
